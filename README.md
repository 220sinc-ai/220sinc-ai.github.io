# ПДА-2М — полевой терминал сталкера

Мобильное приложение-«планшет» в стилистике S.T.A.L.K.E.R.: досье персонажа и
инвентарь со слотами. Работает в браузере, устанавливается на главный экран
Android как обычное приложение и полностью работает офлайн.

Никаких серверов и аккаунтов: все данные (включая фотографию) хранятся только
на устройстве, в `localStorage` браузера.

## Что внутри

**Раздел «Досье»**

- загрузка портрета: обрезка 3:4, сжатие до 720×960, JPEG;
- поля: имя, фамилия, отчество, возраст, прозвище, репутация, особенности;
- преимущества и недостатки: строки с текстом и значением (до 10 в каждом блоке);
- автосохранение при вводе, номер досье и дата обновления.

**Раздел «Инвентарь»**

- четыре контейнера: «Рюкзак», «Разгрузка», «Карманы», «Контейнер»;
- настраиваемое число квадратных слотов у каждого контейнера
  (рюкзак и контейнер — до 48, разгрузка — до 36, карманы — до 24);
- предметы: название, количество, вес одной штуки, состояние, примечание;
- суммарный вес и занятые слоты считаются автоматически;
- перемещение: перетаскивание мышью на компьютере или кнопка «Переместить»
  на телефоне (занятый слот обменивается предметами);
- удаление с отменой действия в уведомлении.

**Раздел «Система»**

- экспорт всех данных в JSON-файл и импорт обратно;
- установка приложения, переключатели скан-линий и вибрации;
- полный сброс с подтверждением.

## Быстрый запуск на компьютере

1. Дважды щёлкните `start.cmd` (или выполните в PowerShell:
   `powershell -ExecutionPolicy Bypass -File serve.ps1`).
2. Откроется `http://localhost:8080/`.
3. Чтобы остановить сервер — `Ctrl+C` в окне консоли.

Параметры запуска:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 9000   # другой порт
powershell -ExecutionPolicy Bypass -File serve.ps1 -NoBrowser   # не открывать браузер
powershell -ExecutionPolicy Bypass -File serve.ps1 -Lan         # доступ с телефона по Wi-Fi
```

`start.cmd -Lan` делает то же самое. В режиме `-Lan` сервер напечатает адрес вида
`http://192.168.1.42:8080/` — откройте его в Chrome на телефоне (компьютер и
телефон должны быть в одной сети; Windows может спросить разрешение для брандмауэра).

## Установка на Android

Полноценная установка PWA (иконка на главном экране, запуск без адресной строки,
офлайн-режим) требует **HTTPS**. `http://localhost` на компьютере тоже подходит,
а вот `http://192.168.x.x` — нет: Chrome не включит service worker.

Варианты:

1. **Хостинг (рекомендуется для телефона).** Загрузите папку проекта на любой
   статический хостинг с HTTPS — например, GitHub Pages или Netlify Drop
   (перетащите папку в браузер). Откройте полученную ссылку в Chrome на Android:
   меню ⋮ → «Установить приложение» / «Добавить на главный экран».
2. **Локально на компьютере.** Откройте `http://localhost:8080/` — можно
   устанавливать и проверять офлайн прямо на ПК (Chrome, Edge).
3. **Быстрая проверка с телефона.** `start.cmd -Lan`, открыть адрес по Wi-Fi.
   Приложение работает и сохраняет данные, но без установки и без офлайн-кэша.

Если нужен именно APK: соберите его из размещённой HTTPS-ссылки через
[PWABuilder](https://www.pwabuilder.com/) (Android → Trusted Web Activity).
Сборка APK в этом проекте не выполняется — для неё нужен Android SDK/Java.

## Данные и резервные копии

- При запуске показывается экран загрузки с перечнем процессов, затем — выбор профиля.
  В пункте «Кладём ЗОНУ в карман» каждый раз появляется случайная шуточная строка.
- Каждый профиль хранится отдельно: `stalker-pda.profile.<ID>`, а список профилей
  и активный профиль — в `stalker-pda.profiles.v1`.
- `stalker-pda.v1` сохраняется как зеркало активного профиля (совместимость со старыми версиями).
- На плашке профиля показывается миниатюра портрета, имя и прозвище; новые профили
  создаются кнопкой «НОВЫЙ ПРОФИЛЬ». Удаление профиля — кнопкой корзины на плашке,
  только после подтверждения; вместе с профилем удаляются его данные.
- Вернуться к выбору профиля можно из раздела «Система → ПРОФИЛИ → ВЫБРАТЬ».
  Удаление или переключение профиля в другой вкладке подхватывается без перезагрузки.
- «Система → Экспорт» скачивает `stalker-pda-ГГГГ-ММ-ДД.json` со всеми полями,
  портретом и инвентарём текущего профиля.
- «Система → Импорт» заменяет данные текущего профиля после подтверждения.
- «Очистить всё» очищает текущий профиль без возможности отмены.
- Портрет хранится как data-URL JPEG и заметно увеличивает размер сохранения;
  при переполнении хранилища приложение покажет ошибку сохранения.

## Файлы проекта

```
index.html            разметка, SVG-спрайт иконок, диалоги
styles.css            тема ПДА, адаптивная вёрстка от 320 px
app.js                состояние, автосохранение, инвентарь, экспорт/импорт
manifest.webmanifest  метаданные PWA
sw.js                 офлайн-кэш (stalker-pda-v1.58.254; Барахолка и каталоги тоже доступны офлайн)
serve.ps1             локальный статический сервер (PowerShell)
start.cmd             запуск сервера двойным щелчком
icons/                иконки приложения (PNG + favicon.svg)
tools/make-icons.ps1  перегенерация PNG-иконок средствами System.Drawing
```

Перегенерировать иконки:

```powershell
powershell -ExecutionPolicy Bypass -File tools\make-icons.ps1
```

## Обновление приложения

После правок `index.html`, `styles.css` или `app.js` увеличьте версию кэша
в `sw.js` (`CACHE_NAME`,например `stalker-pda-v1.58.255`) — иначе браузер может
продолжать отдавать старые файлы из кэша.

## Ограничения

- Нет синхронизации между устройствами: перенос данных — только через экспорт/импорт.
- Данные привязаны к адресу сайта: `localhost:8080` и размещённый сайт — разные хранилища.
- Очистка данных сайта в браузере удаляет досье безвозвратно.
- Приложение не является официальным продуктом GSC Game World; это фанатская
  стилизация под КПК из S.T.A.L.K.E.R.
